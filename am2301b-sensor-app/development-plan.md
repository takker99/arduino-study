# AM2301B Sensor App: Prototype駆動開発計画

## 概要
Arduino Uno R4 + AM2301B温湿度センサー + Web SPA (preact+vite) の制御・可視化システムを、実機テストを繰り返しながら段階的に開発する。

---

## 開発サイクル

### 1. MVP動作確認
- ダミーデータ送信＋Web SPAで受信・表示
- 実機テストで通信・表示が正常か確認
- 問題があれば即修正

### 2. 履歴保存・グラフ描画機能追加
- 受信データを配列で保存
- Chart.jsで温度・湿度の推移グラフ表示
- 実機テストでグラフ描画・パフォーマンス確認

### 3. エラー処理・切断対応
- 通信エラー時のUI表示
- 切断ボタン・再接続機能
- 実機テストで異常系動作確認

### 4. UI/UX改善・デザイン強化
- レイアウト・スタイル調整
- スマホ対応・アクセシビリティ
- 実機テストで操作性確認

### 5. 知見・トラブルシュート記録
- `knowledge/`に技術的課題・解決策を随時記録
- 開発サイクルごとに知見を蓄積

---


## 運用ルール
- 各ステップは「実装→実機テスト→修正→知見記録」のサイクルで進行
- 実機テスト後、必ずその段階のコードをcommit（進捗・履歴管理のため）
- 変更は意味単位ごとに分割してcommitする
- commitメッセージはConventional Commit規約に則り英語で書く
- すべての変更をcommitし切ってから次のステップに進む
- git_stage（git status）で全変更がcommit済みか必ず確認する
- 進捗・課題はチャットで随時報告（実機テスト依頼時のみ）
- 重要な知見は`knowledge/`にMarkdownで体系化
