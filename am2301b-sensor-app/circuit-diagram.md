# AM2301B + Arduino UNO R4 WiFi 接続回路図

## 部品リスト
- Arduino UNO R4 WiFi
- AM2301B 温湿度センサー
- 10kΩ プルアップ抵抗
- ブレッドボード
- ジャンパーワイヤー

## 接続図

```
Arduino UNO R4 WiFi        AM2301B (DHT21)
┌─────────────────┐        ┌──────────────┐
│                 │        │              │
│ 5V    ◯─────────┼────────┼─◯ VCC (Pin1) │
│                 │        │              │
│ GND   ◯─────────┼────────┼─◯ GND (Pin4) │
│                 │        │              │
│ D2    ◯─────────┼────────┼─◯ DATA(Pin2) │
│                 │        │              │
│                 │        │   ◯ NC (Pin3)│
│                 │        │              │
└─────────────────┘        └──────────────┘
                                   │
                           10kΩ    │
                       ┌─resistor──┤
                       │           │
                   5V ─┘           │
                               DATA pin
```

## 詳細接続

| Arduino UNO R4 | AM2301B | 説明 |
|---------------|---------|------|
| 5V | Pin 1 (VCC) | 電源供給 (3.3V-5V) |
| GND | Pin 4 (GND) | グランド |
| Digital Pin 2 | Pin 2 (DATA) | データ通信 |
| - | Pin 3 | 未接続 (NC) |

## プルアップ抵抗

### 推奨：外付け10kΩ抵抗
- AM2301BのDATAピン(Pin2)とVCC間に10kΩのプルアップ抵抗を接続
- 最も安定した通信が可能

### 代替案：Arduino内蔵プルアップ（抵抗がない場合）
- ファームウェアで `pinMode(DHTPIN, INPUT_PULLUP);` を使用
- 外付け抵抗がなくても動作する可能性あり
- 不安定になる場合は外付け抵抗を検討

### 抵抗なしの場合
- 短い配線（10cm以下）なら動作することもある
- エラーが頻発する場合は上記の対策を実施

## 注意事項
1. AM2301Bは3.3V-5V動作のため、Arduino UNO R4の5V電源で問題なし
2. データ線は必ずプルアップ抵抗が必要
3. センサーとArduino間の距離は短く（20cm以内推奨）
4. 初回読み取り前に2秒程度の待機時間が必要

## ピン配置 (AM2301B正面から見て)
```
    ┌─────────┐
    │  ○ ○ ○ ○  │
    │  1 2 3 4  │
    └─────────┘

Pin 1: VCC (赤)
Pin 2: DATA (黄/緑)
Pin 3: NC (未接続)
Pin 4: GND (黒)
```
