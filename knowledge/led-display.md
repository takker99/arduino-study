# UNO R4 Wi-Fi LED マトリクス表示仕様 (校正MVP)

## 概要
Arduino UNO R4 Wi-Fi には 12×8 LED マトリクスが搭載されており、最小限の状態フィードバックに活用しています。校正MVPではセンサー読み取り値の符号付き2桁 (計3文字) を簡易表示します。

## 表示フォーマット
```
<sign><d1><d2>
```
- `<sign>`: `+` または `-`
- `<d1><d2>`: 絶対値 |v| の下位2桁 (ゼロ埋め)
- 表示関数: `showValue(long v)` (ファームウェア `main.cpp` 内)

例:
| センサー値 v | 表示 | 備考 |
|--------------|------|------|
| 7            | +07  | 正数ゼロ埋め |
| -3           | -03  | 負数ゼロ埋め |
| 125          | --   | 範囲外 (|v|>99) |
| -842         | --   | 範囲外 |

## 範囲外処理
`|v| > 99` の場合は視認的に分かりやすくするため `--` を表示 (符号を含めない 2 文字)。コード上は `strncpy(buf, "--", ...)` で埋め込み。

## 更新タイミング
- 各サンプリング周期 (測定成立時) に `showValue` 呼び出し
- センサー未準備(`status=NOT_READY`)時は保守的に `showValue(0)` で `+00` を表示 (ドロップでなく既知パターン)

## 実装抜粋
```cpp
void showValue(long v) {
  char buf[4] = {0};
  long av = std::labs(v);
  if (av > 99) {
    std::strncpy(buf, "--", sizeof(buf));
  } else {
    char sign = (v < 0) ? '-' : '+';
    std::snprintf(buf, sizeof(buf), "%c%02ld", sign, av);
  }
  matrix.beginDraw();
  matrix.stroke(0xFFFFFF);
  matrix.textFont(Font_4x6);
  matrix.beginText(0, 1, 0xFFFFFF);
  matrix.print(buf);
  matrix.endText();
  matrix.endDraw();
}
```

## 設計判断理由
| 項目 | 現行方針 | 理由 / トレードオフ |
|------|----------|----------------------|
| 桁数 | 符号+2桁 | マトリクス領域と可読性の最小公倍点 |
| スケール | 未適用 (生値下位2桁) | 実装簡易化 / 先に回帰モデル確立優先 |
| 範囲外 | `--` | 異常/大きい値を即識別 |
| 未準備値 | `+00` | 安定視認性 (点滅/空白を避ける) |

## 今後の拡張案
| 案 | 説明 | メリット |
|----|------|----------|
| オートスケール | 値の桁に応じ倍率表示 (k, M 等) | 広いダイナミックレンジ対応 |
| バー表示 | ノイズ幅をバー長で即時可視化 | 安定判定トレンド把握 |
| ステータス記号 | `R`=Ready, `M`=Measuring 等 | 状態判別容易化 |
| エラーパターン点滅 | NOT_READY頻発で点滅 | 物理トラブル即検知 |

## 関連コード
- `main.cpp` : `showValue`, `maybeSample` 内呼び出し
- シリアル送信との整合: 数値はシリアルで完全値を PC 側が把握し、LED は簡易インジケータ役
